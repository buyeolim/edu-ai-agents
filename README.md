# edu-ai-agents

## 에이전트 설계

### 이름

피아노 학습 보조 에이전트

### 목적

사용자의 레슨/연습 데이터를 체계적으로 관리하고, 가용 시간에 맞춘 효율적인 연습 루틴을 설계하며, 수준에 맞는 곡을 추천하여 학습의 지속성을 돕습니다.

### 핵심 기능

1. 안내자 에이전트

시스템의 입구에서 사용자의 의도를 파악하고 데이터 검증

- **입력 분류**: 사용자가 '기록'을 원하는지, '설계'를 원하는지, '추천'을 원하는지 판단
- **가드레일**: 피아노 학습과 관련 없는 대화 차단
- **정보 보완**: 스케줄 생성 등에 필요한 필수 정보(연습 시간 등)가 빠졌을 때 되묻기

2. 기록 담당자 에이전트

대화 내용을 기반으로 예시와 같은 '정규화된 문서' 작성

- **데이터 추출**: 레슨 범위, 숙제, 목표 BPM, 주의사항 등 핵심 지표 추출
- **문서화**: 흩어진 대화를 바탕으로 레슨/연습 기록지 생성
- **문서저장**: 생성된 기록을 저장하여 다른 에이전트 활용

3. 연습 설계사 에이전트

가용 시간과 숙제 데이터를 바탕으로 '오늘의 연습 분량' 설정

- **시간 배분**: 총 연습 시간을 곡별 난이도와 중요도에 따라 분(min) 단위로 배분
- **미션 가이드**: 단순 곡명이 아닌 "어디부터 어디까지, 몇 BPM으로 몇 번"과 같은 구체적 지침 하달

4. 길잡이 에이전트

현재 실력을 진단하고 다음 목표 제시

- **수준 진단**: 기록된 진도와 숙련도를 바탕으로 현재 사용자의 연주 레벨 도출
- **맞춤 추천**: 사용자가 선호하는 장르와 현재 실력이 교차하는 지점의 곡 제안
